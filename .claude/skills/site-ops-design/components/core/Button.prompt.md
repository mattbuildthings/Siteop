Primary interactive button; use `accent` for the single most important action on a screen, `primary` for standard actions, `secondary`/`ghost` for lower emphasis.

```jsx
<Button variant="accent" size="lg">Start Site Walk</Button>
<Button variant="secondary" icon={<CameraIcon/>}>Attach Photo</Button>
```

Variants: primary, accent, secondary, ghost, danger. Sizes: sm (32px), md (40px), lg (48px).
